# Hyperium Launcher

Launcher e client de Minecraft 1.8.9 com mais de 80 mods de PvP, HUD e utilidades.

## Download

Baixe a versão mais recente em **[Releases](https://github.com/arthwr14/hyperium-launcher/releases/latest)**:

| Sistema | Arquivo |
|---|---|
| Windows | `Hyperium-Setup-<versão>.exe` |
| macOS (Apple Silicon, M1 em diante) | `Hyperium-Launcher-<versão>-arm64.dmg` |
| macOS (Intel) | `Hyperium-Launcher-<versão>-x64.dmg` |
| Linux (Ubuntu/Debian) | `Hyperium-Launcher-<versão>-amd64.deb` |
| Linux (outras distros) | `Hyperium-Launcher-<versão>-x86_64.AppImage` |

**macOS:** na primeira vez, clique com o botão direito no app e escolha **Abrir**.

O launcher se atualiza sozinho quando sai uma versão nova.
